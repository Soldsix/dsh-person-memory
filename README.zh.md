# dsh-person-memory

[English](README.md) | 中文

## 摘要

一个按需启用的 DSH 人物记忆插件。按命名空间、账号、会话和人物隔离，保留更正历史，并原子遗忘同出处的关联记忆。原生设置和查询页面可独立于模型工具使用；可选可信工具支持提议、读取、更正和遗忘。自述始终有明确来源，不代表客观事实已获独立验证。本开发版尚不提供自动提取、语义检索、上下文注入或完整备份恢复。

<a id="install"></a>
## 安装与组合

适配 DSH 0.2.2-rc.1、Cordis ~4.1.0。原生 DSH profile 需要 Node >=24.9；库及运行时兼容性另覆盖 Node 22.19。插件不安装命令行应用或独立服务，初始关闭，也不会加载现有机器人的数据。

```sh
dsh plugin --profile MY_PROFILE add https://github.com/Soldsix/dsh-person-memory/releases/download/v0.1.0-development/dsh-person-memory-0.1.0-development.tgz
```

在原生“插件”页面打开本插件，启用记忆并选择租户、网络、机器人账号、群或私聊对象。筛选列表取交集，不表示账号与群的配对。目录留空使用 `PROFILE/data/person-memory/NAMESPACE`；自定义目录必须为当前命名空间专用的绝对路径。

```yaml
- id: person-memory
  config:
    enabled: true
    namespace: personal
    tenants: [example-tenant]
    accounts: [example-bot]
    groups: [example-group]
    privatePeers: []
    operators: []
    toolsEnabled: false
```

可选 `im` 提供方会记录所选范围的标准化来源，包括未向机器人提问的消息，不产生回复。Host 服务也接受明确标记的实时或归档来源。本插件独立管理存储，无须强制安装归档、Chat 或传输插件；按组合需求添加即可。`dsh-im-kit` 和 `dsh-im-requests` 为公开库依赖。

<a id="authority"></a>
## 身份与权限

人物由命名空间以及租户、网络、机器人账号、会话类型与 ID、成员 ID 共同确定。私聊人物必须等于选定私聊对象。普通 Host 调用只能读写已认证的本人；配置的跨人物读取者可读取所选范围内的其他人，但模型不能借此写入别人的记忆。Profile 所有者通过独立的仅所有者 RPC 管理记忆。

同进程 Host 插件和本地管理员属于可信方，必须将服务参数绑定到已认证事件，并选择合适的输出对象。模型结果可能被引用到公开群回复中，存储隔离不等于私密投递。本服务无法隔离恶意 Host 代码，也不会自行合并跨账号或跨群身份。

<a id="revisions"></a>
## 出处与版本

`observe` 按消息身份、时间和摘要保存一次来源文字。相同消息 ID 更换内容或发送者时报告冲突。附件仍由来源负责保存，此库只记录是否存在附件，不复制其字节。每个提议必须引用该人物来源中实际存在的原文；出处缺失或不匹配时拒绝写入。

记忆使用逻辑键、乐观锁 `expectedVersion`、变更 ID，以及分别表示生效和记录时点的 `effectiveAt` / `recordedAt`。新来源可以更正已有键或追溯生效时间，同时保留旧版本；旧来源提取不能覆盖较新的更正。查询先确定两个时点下最新可见的版本，再按接纳状态筛选，避免将未接纳的新更正之前的旧结论误作当前结论。

普通提取保留为 `candidate`。实时来源以支持的记忆指令开头，且内容逐字出现在引文内时，可记录为 `user-requested`。明确标记的 `joke`、`roleplay`、`third-party` 不进入默认检索。所有者接纳会追加保留原始出处的 `owner-confirmed` 版本。这些状态表示接纳程度而非事实真伪；字面规则不能理解所有否定、反讽或自然语言意图。

查询是在一个人物的内容和引文中进行有界、区分大小写的精确子串匹配，不是语义检索。`partial` 与 `next` 用于区分扫描受限和确实没有结果。加密游标绑定命名空间、人物、请求者、查询词、时间窗口和人物版本；变更或重启后旧分页失效。

<a id="forgetting"></a>
## 遗忘

遗忘会删除目标键的全部版本，以及通过出处传递关联的所有键，同时清除这些来源文字，保留带版本的遗忘标记、摘要和变更回执。一次可能清除多个关联键；回执分别说明总数和返回的键列表是否受限。关联数量超出配置上限时拒绝整个操作，不会只遗忘一部分。

重放不能恢复已清除的来源。人物级序号水位线会阻止遗忘后再次提取旧材料；后续补录中早于该人物遗忘时点的历史来源也会被屏蔽。新的实时来源允许较粗的时间戳；重新启用已遗忘的键，需要新的明确记忆请求、`reopen: true` 和保留的期望版本。旧变更只返回有界的当前版本信息，不会重新写入原内容。

本操作不会删除 QQ 归档、已经记录的 DSH 工具结果、其他存储、导出文件或系统备份，也不等于取证级安全擦除。不要用旧数据库副本覆盖新库，否则新的遗忘标记也会被覆盖。跨存储清理和陈旧模型上下文替换属于上下文记忆集成，目前尚未完成。

<a id="model-tool"></a>
## 原生模型工具

使用 dsh-qq-chat 0.3.0-development 或兼容的 `imRequests` 提供方。启用按成员隔离的群会话，将 `person_memory` 加入 Chat 允许名单，再启用本插件的 `toolsEnabled`。缺少提供方或使用共享群会话时不能启用该工具。预览、复制的 agent ID 和保存的会话元数据均不授予权限；原生工具结果会进入会话日志。

操作包括 `recall`、`head`、`remember` 和 `forget`。范围、操作者、出处消息与变更 ID 固定来自实时 Host 请求。只有读取操作可以选人物，且仍须通过当前会话内的权限检查。记忆需要准确引文和当前期望版本；遗忘需要来源以支持的明确遗忘指令开头。模型参数不能将候选升级为所有者接纳，也不能虚构出处。

规范结果区分拒绝、查询窗口、有界分页和变更回执。实时来源被取消或替换后丢弃迟到的读取结果。写入回执丢失时操作可能已提交；收到 `write-uncertain` 后应先查询当前版本，不能盲目重试。引文是非可信数据，不能改变工具权限。支持原生通用工具卡片及 Web 通用回退展示。

<a id="owner-ui"></a>
## 所有者界面

原生“插件”页面提供全部持久配置，以及不含正文的服务与工具状态。保存时核对配置版本，等待记忆及工具操作空闲，只重启本服务。失败草稿可继续编辑；运行时加载失败时，可先在页面关闭后修复配置。受支持的重载、卸载和重装会保留来源、记忆版本和遗忘标记。

查询面板要求明确选择人物和会话，支持已接纳及候选视图、时间窗口、有界分页、所有者接纳与关联遗忘。数据代际变化时会清除陈旧展示。导出会重新验证当前选择，下载带 `completeBackup: false` 的单页 JSON；它不是全量导出或恢复包。不要把这些文件公开为开发证据。

<a id="storage"></a>
## 存储与生命周期

此存储由 SQLite 应用标识和单调递增的 schema 版本 1 确定。外来数据库、未来版本或命名空间不符时拒绝打开，不改写其数据库。PID 与随机令牌租约阻止两个活进程同时占用；只有原进程已消失才回收遗留租约。WAL、完整同步和事务更新保留已提交版本。明文存储需要 profile 级文件系统保护。

SQLite 运行在独占 worker 中。队列数量与字节、文本、扫描与结果、锁等待和超时均可配置。写入超时后仍跟踪至回执到达。卸载会取消并等待所属工作及 worker 退出。存储故障会被明确报告，不以静默停用记忆掩盖。来源入库本身不调用模型或消息传输。

<a id="verification"></a>
## 验证与限制

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm pack --pack-destination artifacts
npm run test:consumer
npm run test:native
npm run test:browser -- --with-deps
npm run test:web
```

测试只使用合成人物与来源。原生模型测试通过真实 DSH 适配器访问受控本机 HTTP，覆盖并行会话、所有者权限、更正与遗忘、重载，以及 SQLite 被锁时聊天先回复。浏览器测试运行隔离的无头原生 Web profile。独立消费者验证安装包逐字节一致、严格类型声明且不借用祖先目录依赖。这些结果不能证明真实模型提取质量或 QQ 客户端投递效果。

本版提供有出处的记忆存储与工具组件。自动提取、向量及语义检索、公共话题、按 token 预算注入与压缩、陈旧会话结果替换、全量导出导入恢复和离线历史恢复均属于尚未完成的独立工作。安装不会迁移正式 profile、人设、skills、归档或记忆。
